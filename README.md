# SkyPro Kanban

_Учебный проект по frontend-разработке_

Веб-приложение для управления задачами по методологии Kanban.
Пользователь может создавать, редактировать и удалять задачи, отслеживать их прогресс, перемещать между этапами выполнения и работать с персональным рабочим пространством после авторизации.

## Функциональность

### Авторизация и регистрация

* Регистрация нового пользователя.
* Авторизация существующего пользователя.
* Валидация данных форм.
* Отображение ошибок при авторизации и регистрации.

### Организация задач

Задачи распределяются по колонкам:

* Без статуса
* Нужно сделать
* В работе
* Тестирование
* Готово

### Работа с задачами

* Создание новых задач.
* Редактирование существующих задач.
* Удаление задачи.
* Изменение статуса задачи.
* Просмотр подробной информации о задаче.

### Дополнительные возможности

* Drag-and-Drop для перемещения карточек между колонками.
* Продвинутые уведомления с использованием React-Toastify.
* Поддержка светлой и тёмной темы.
* Адаптивная верстка для мобильных устройств.
* Обработка ошибок сервера во всех запросах.
* Отображение состояния загрузки.
* Страница 404 для несуществующих маршрутов.
* Сообщение «Новых задач нет» при отсутствии задач.

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/kors-ak/skypro-kanban.git
```

### Установка зависимостей

```bash
npm install
```

### Запуск проекта

```bash
npm run dev
```

Приложение будет доступно по адресу:

```text
http://localhost:5173
```


## Архитектурные решения

- Глобальное состояние реализовано через Context API
- Работа с API вынесена в отдельный слой сервисов
- Смена темы реализована через ThemeProvider и Styled Components
- Навигация построена на React Router
- Drag-and-Drop реализован с использованием библиотеки @dnd-kit


## Дополнительные фичи

### Поддержка тёмной темы

Полноценная поддержка светлой и тёмной тем интерфейса. Пользователь может переключаться между режимами в любой момент без перезагрузки страницы.

Для реализации использовались Styled Components и ThemeProvider. Все цвета интерфейса (фон, текст, кнопки, карточки задач, модальные окна и элементы форм) вынесены в отдельные объекты тем, что позволяет централизованно управлять оформлением приложения и поддерживать единый стиль во всех компонентах.

Переключение темы происходит динамически и мгновенно применяется ко всем элементам интерфейса. Выбранная пользователем тема сохраняется в localStorage и автоматически восстанавливается при повторном открытии приложения.

### Drag-and-Drop для управления задачами

Возможность управления задачами с помощью технологии Drag-and-Drop на базе библиотеки @dnd-kit.

Пользователь может перемещать карточки задач между колонками канбан-доски простым перетаскиванием мышью. При изменении положения карточки автоматически обновляется её статус, а изменения синхронизируются с сервером.

Функциональность обеспечивает более удобное и интуитивно понятное взаимодействие с доской задач по сравнению с изменением статуса через форму редактирования. Для реализации использовались компоненты DndContext, DragOverlay и механизмы обработки событий перетаскивания из библиотеки @dnd-kit.

В результате пользователь может управлять рабочим процессом непосредственно на доске, быстро перемещая задачи между этапами выполнения.

### Система уведомлений

Для информирования пользователя о результатах выполняемых действий в приложении реализована система уведомлений на базе библиотеки React-Toastify.

Уведомления отображаются при возникновении ошибок. Пользователь получает мгновенную обратную связь при создании, редактировании, удалении и перетаскивании задач, а также при возникновении проблем с сетью или сервером.

Использование toast-уведомлений позволило отказаться от стандартных alert-окон браузера и сделать взаимодействие с приложением более современным и удобным. Уведомления отображаются поверх интерфейса, не блокируют работу пользователя и автоматически скрываются через заданный промежуток времени.
